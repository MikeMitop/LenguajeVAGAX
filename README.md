## Cómo ejecutar los ejemplos

El proyecto cuenta con varios ejemplos, entre ellos los tres principales que hemos trabajado:
- `euclides.vagax` (Algoritmo de Euclides para el Máximo Común Divisor)
- `bubblesort.vagax` (Algoritmo de ordenamiento Bubble Sort usando listas)
- `taylor_exp.vagax` (Aproximación de la función exponencial usando la serie de Taylor)

Para ejecutar cualquiera de estos archivos, debes correr el script `main.py` desde la raíz del proyecto. El script ya está configurado para buscar el código directamente dentro de la carpeta `ejemplos/`.

**Pasos de ejecución:**

1. Abre tu terminal asegurándote de estar en la raíz del proyecto (`/LenguajeVAGAX`).
2. Ejecuta el archivo principal:
   ```bash
   python main.py
   ```
3. La consola te pedirá que ingreses el nombre del archivo. Escribe únicamente el nombre con su extensión `.vagax` (no incluyas la ruta `ejemplos/`). Por ejemplo:
   ```text
   Ingrese el archivo .vagax: bubblesort.vagax
   ```
4. Presiona **Enter** y el intérprete ejecutará el código y mostrará los resultados por consola.
